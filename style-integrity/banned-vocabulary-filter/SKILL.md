# Banned Vocabulary Filter

## When To Use
- A manuscript or technical report reads as if generated by an LLM.
- Draft contains filler verbs (delve, leverage, harness, facilitate, utilize).
- Cliché phrases appear: "plays a vital role", "stands as a testament", "in the broader landscape".
- Style review forbids rhetorical intensifiers (paramount, pivotal, crucial).

## Workflow
1. Tokenize the manuscript sentence by sentence.
2. Match each banned term against the replacement table below (case-insensitive, whole-word).
3. Substitute with the recommended synonym. Adjust surrounding grammar (verb tense, article agreement) so the sentence still parses.
4. Re-read every modified sentence for coherence and register.
5. Log each substitution in a change report: line, original, replacement, justification.
6. Re-scan to confirm zero banned terms remain.
7. Output the cleaned text plus the change report.

## Inputs
- Manuscript text (LaTeX, Markdown, or plain text).
- Optional project-specific banned-terms extension list.
- Optional allow-list of terms the user wants to keep.

## Outputs
- Cleaned text with all banned terms replaced.
- A change report: line number, original, replacement.

## Key Rules
- Every banned term must be replaced, not deleted.
- Replacements preserve grammatical correctness.
- Case is preserved when substituting (e.g., `Delve` → `Examine`).
- Phrases are matched as whole phrases before individual words.

## Replacement Table (regex/sed-style)

| Banned | Replacement |
|--------|-------------|
| `\bnovel\b` | `new` |
| `\bdelve\b` | `examine` |
| `\brigorous\b` | `thorough` |
| `\brigorously\b` | `thoroughly` |
| `\bparamount\b` | `most important` |
| `\bleverage\b` | `use` |
| `\bcrucial\b` | `important` |
| `\btestament\b` | `evidence` |
| `\bunderscore\b` | `highlight` |
| `\bmultifaceted\b` | `complex` |
| `\bnavigating\b` | `working with` |
| `\brealm\b` | `field` |
| `\btapestry\b` | `structure` |
| `\bintricate\b` | `detailed` |
| `\brobust\b` | `stable` (figurative use only) |
| `\bseamless\b` | `smooth` |
| `\bpivotal\b` | `central` |
| `\bharness\b` | `use` |
| `\bfacilitate\b` | `enable` |
| `\butilize\b` | `use` |
| `\bauthored\b` | `wrote` |
| `It is worth noting` | `` (delete the throat-clearer, keep the clause) |
| `In conclusion` | `` (delete; let the closing paragraph stand alone) |
| `plays a vital role` | `is central to` |
| `stands as a testament` | `shows` |
| `broader landscape` | `field` |

## Examples

Before:
```
This work leverages a novel architecture that plays a vital role in
navigating the multifaceted realm of representation learning. It is worth
noting that our approach stands as a testament to the broader landscape.
```

After:
```
This work uses a new architecture that is central to working with the
complex field of representation learning. Our approach shows this trend.
```
